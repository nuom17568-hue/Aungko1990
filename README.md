# Aungko1990 Work

A small Python utility project for text normalization examples.

## Usage

```python
from aungko1990 import normalize_title, slugify

normalize_title("  Aungko1990   Work  ")  # "Aungko1990 Work"
slugify("Café Guide: Aungko1990 Work!")  # "cafe-guide-aungko1990-work"
```

## Development

Run the test suite with:

```bash
python -m pytest
```
